WHAT YOU DID RIGHT

远见之择 · 您已经做对的事

在任何建议之前，先为这些事点赞——很多家庭还没走到这一步。

✓ 全家三口都有健康守护金——为每位家人建起第一道防线，这是最重要的一步。
✓ 夫妻俩都有大额医疗兜底——账单再大，都有机制接得住。
✓ 养老储备已经起步——提前布局退休后的现金流，眼光放得远。
✓ 所有保单干净、无质押——资产状态健康，权益完整。
✓ 保障期覆盖责任最重的岁月——主要保单保至60岁，与房贷、学业的高峰期基本匹配。

小结：为家人提前筑起防线，本身就是一份沉甸甸的"远见之择"与爱的表达。接下来的完善，是锦上添花，不是否定过去。

定位：增值服务工具，不是销售工具。全程"三不讲"——不讲产品、不报价格、不催决定。让客户自己勾出"不确定"，比您指出来效果好十倍。

开场（照着说）："X哥/X姐，今天占用您20分钟，帮咱家做一次'保障健康体检'——跟车要年检、身体要体检一个道理。今天不聊任何新产品，只看三件事：钱够不够用、钱到时候归谁、钱顺不顺利拿到。一页一页过，您随时打断我。"
第一问过渡："第一笔钱，看够不够花——万一节奏被打乱、需要用钱的关键时刻，给的钱够不够撑住咱家的正常日子。我先说好：够用就踏实，有空间也只是心里有个数，补不补您说了算，今天量个体温而已。"
第二问过渡："第二笔钱，看归谁。跟提前安排家事一个道理——现在理清楚，将来家里人省心，也免得一家人因为钱伤和气。这不是忌讳事，恰恰是对家里人最负责任的安排。"
第三问过渡："第三笔钱，看顺不顺。保单不是办完就一劳永逸，几个小细节到位，关键时刻才不卡壳。咱们提前把'堵点'排掉。"
收尾（关键）："盘完了：安心的有X项，您之前规划底子是真不错；可优化的都是小事，要打的电话、要带的资料我写在纸上了；建议优先完善的X项——今天不催您定。回头我把行动清单整理好发您，您跟家里商量着看。要办，咱约时间细聊；不急，留着当备忘。我这个电话，随时打得通。"
  • 笔递到客户手里——自查区让客户自己勾，自己勾出来的"不确定"才有触动；
  • "优先完善"项只登记、不讲产品——统一话术："这项我记下来，回头给您出个参考"；
  • 行动清单是二次触点——必须承诺"整理好发您"，这是下次见面的天然理由；
  • 所有建议落到纸面——当场不定≠不成交，客户带走的是可以回家商量的凭据；
  • 结束必留一句："您家情况我都建档了，有政策、服务变化我第一时间告诉您。"
  • 用词口径：本模板已全程使用暖心说法（关键时刻／安心休养／留给家人的钱／守护不断档），现场请保持同一口径，不要脱口而出行业词。
